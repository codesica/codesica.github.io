# 中文阅读排版

本次仅改前台阅读层，不改 Markdown 文章、URL、RSS、内容集合或依赖版本。

- 系统中文无衬线字体，站名、导航、日期和正文统一字体体系。不再加载 Snell、STIX 或 EarlySummer 网页字体。
- 720px 居中单栏；手机左右 20px；横向顶部导航；没有固定侧栏。
- 手机正文 17px / 1.8 行高，标题 27px，小标题 22px；桌面正文 18px。
- 左对齐、正常字距，不使用两端拉伸；代码使用独立等宽字体并横向滚动。
- 目录使用原生 details 元素，默认折叠；保留深浅色、代码复制、图片查看和主题来源许可证。
- 样式入口：src/styles/reading.css。外壳：src/layouts/Layout.astro。文章结构保持原路由文件。

这是中文技术博客阅读习惯的定制，不是某位博主网页的复制，也不宣称字号是统一的中文标准。

修改先在 design/ 分支构建和检查，再发布 main。preview.yml 无部署权限；截图只包含本站页面，不包含字体文件。
